# 04 · 数据采集方案：拉取小红书帖子 / 评论数据

> 目的：采集目标赛道的笔记数据（标题、点赞、收藏、评论数）与评论内容，用于竞品分析和选题。
> ⚠️ 合规边界：仅限个人研究竞品与选题分析，采集频率必须克制（低频、限页），不得用于批量搬运、刷量或任何违反平台规则的用途。小红书有严格的反爬机制（x-s/x-t 签名、登录态校验），采集脚本随时可能失效。

## 方案对比

| 方案 | 能拿到什么 | 成本 | 适用 |
|---|---|---|---|
| A. 手动浏览 + 记录 | 单篇笔记数据 | 零成本 | 起号期每天看 3-5 篇足够 |
| B. 官方创作者中心 | 自己笔记的完整数据（曝光/点击率/收藏率） | 零成本 | 复盘必用 |
| C. Python 脚本（本仓库 `scripts/xhs_collector.py`） | 关键词搜索结果笔记列表 → CSV | 需登录态 | 批量竞品监控 |
| D. 开源项目 MediaCrawler | 笔记+评论+作者数据，Playwright 模拟真实浏览器 | 需部署，抗反爬最强 | 深度评论分析 |
| E. 第三方数据平台（千瓜数据 / 新红 / 灰豚数据） | 行业大盘、赛道排行、爆文榜、达人榜 | 免费+付费版 | 赛道决策（最省事、最合规） |

**推荐组合**：赛道决策用 E（千瓜免费版够用）→ 日常竞品用 A+C → 自己的数据用 B → 评论深度分析用 D。

## 方案 C：本仓库脚本使用方法

1. 获取登录态 Cookie：浏览器登录小红书网页版 → F12 → Network → 复制任意请求的 `Cookie` 头。
2. 配置环境变量（不要把 cookie 提交到仓库）：

```bash
export XHS_COOKIE="粘贴你的cookie"
```

3. 运行：

```bash
pip install requests pandas
python scripts/xhs_collector.py --keyword "桌面收纳" --pages 2
# 输出 → data/xhs_notes_桌面收纳.csv
```

4. 输出字段：`标题 | 作者 | 点赞 | 收藏 | 评论数 | 笔记ID | 链接`，可直接用 pandas 做收藏率排序分析。

## 方案 D：MediaCrawler（评论采集首选）

```bash
git clone https://github.com/NanmiCoder/MediaCrawler.git
cd MediaCrawler && pip install -r requirements.txt && playwright install chromium
# 修改 config/base_config.py：
#   PLATFORM = "xhs"
#   CRAWLER_TYPE = "search"  (关键词搜笔记) 或 "detail" (指定笔记抓评论)
#   KEYWORDS = "桌面收纳"
#   ENABLE_GET_COMMENTS = True
#   SAVE_DATA_OPTION = "csv"
python main.py --platform xhs --lt qrcode   # 首次扫码登录
```

输出到 `data/xhs/` 目录：`search_contents CSV`（笔记）+ `comment CSV`（评论，含点赞数、IP 属地）。
评论分析方向：高频"求链接/求平替"词 = 高转化意图信号；高频吐槽点 = 选题机会。

## 每周数据工作流（建议固定周日执行）

1. 脚本采集本周目标关键词笔记 → CSV 存 `data/`（按日期命名）。
2. 筛选收藏率异常高的 3 篇 → 拆解进选题库。
3. 记录自己账号数据到 `data/notes_log.csv`（曝光/点击率/收藏率/评论）。
4. 对照 `03-爆款方法论` 达标线，决定下周是调封面还是调内容结构。
