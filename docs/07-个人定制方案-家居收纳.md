# 07 · 个人定制方案（最终定稿）：家居收纳 / 租房改造

> 本文档是**最终执行方案，优先级最高**，覆盖 01/02/06 的通用结论。
> 画像：程序员（不愿以技术身份出镜）、会用 AI、无货源、不出镜、坐标东莞/广州、家有可拍空间 + 厨房场景。
> 定稿过程：曾倾向「AI 工具干货」赛道，因个人兴趣不足 + 知识付费变现周期偏慢（万粉后才真正起飞）而放弃。

## 一、赛道决策（定稿）

**主线：家居收纳 / 租房改造（好物分享）**，厨房场景作为内容延展（厨具/厨房收纳）。

| 维度 | 判断 |
|---|---|
| 兴趣 | 本人选定（起号最大的成败变量）✅ |
| 不出镜 | 拍环境空镜 + 手部操作 + 改造前后对比，全程无需真人 ✅ |
| 无货源 | 不开店不囤货，纯挂车佣金 + 商单 ✅ |
| 变现速度 | 收藏率全品类最高（↑65%）、家居是蒲公英商单大户、挂车 0 粉可做，现金流早于 AI 干货线 ✅ |
| 场景资源 | 家有可拍空间 + 厨房 ✅ |
| 竞争 | 低于美妆/穿搭，且"素人感"内容反而更有优势 ✅ |

**AI 的角色 = 生产力工具，不是内容主题**：选题对标、文案初稿、封面图排版、AI 配音、数据复盘全部用 AI 提效，把单人产能拉到"日更"可行。

**副线储备（不立即启动）**：广莞探店（需外出频率确认后再开）；「收纳师服务」接单（300-800 元/单，万粉前靠主页接，万粉后内容反哺）。

## 二、不出镜的拍摄方案（实操）

- **封面**：改造前后对比图 / 9 宫格清单图（Canva/AI 排版），大字标题。
- **内页**：环境空镜（无人物）、手部特写（拍手操作即可）、产品实拍 3-5 张。
- **视频形态**（第 5 周起）：录屏式改造过程 + AI 配音（TTS 生成）+ 字幕；沉浸式收纳（无解说纯 BGM）完播率天然高。
- **人设感来源**（不靠脸）：第一人称文案（"我把出租屋的 3㎡ 改成了……"）、固定结尾口头禅、每篇自曝一个踩坑。

## 三、AI 生产工作流（程序员用法）

```
选题：scripts/xhs_collector.py 采关键词 "桌面收纳/租房改造" Top 互动笔记
      → 找收藏率异常高的结构 → AI 批量生成变体标题
文案：AI 出初稿 → 手动加 1 个真实踩坑细节（保留素人感，防 AI 味）
封面：AI 生成排版框架 → Canva/稿定套模板 → 9:16 导出
视频：剪辑用剪映，配音用 TTS，字幕自动识别
复盘：每周日 data/*.csv → AI 帮算收藏率/点击率 → 决定下周调封面还是调结构
```

⚠️ 红线：正文不能整篇 AI 味直出（平台对 AIGC 文字检测趋严），必须手改 20-30%；封面可用 AI 排版，但商品/场景图必须实拍。

## 四、变现路径（三段式）

```
第 1-3 个月（0→千粉）：
  收纳图文起号（选题库见 templates/选题库-好物分享.md）
  + 笔记挂车：收纳盒/免打孔架/厨房分区（家居佣金 10-25%，0 粉可做）
  + 每周接 1-2 个素人通告（30-200 稿费 + 免费产品，反哺拍摄素材）

第 4-6 个月（千粉后）：
  开蒲公英：家居/厨具/日百类商单（千粉 200-400/条，家居赛道 500 粉有机会人工审核开通）
  + 挂车继续 → 商单+佣金双线（官方数据：双线账号 3 年收入是单线 2 倍）
  + 加录屏式改造视频 + AI 配音

第 7 个月以后（5000 粉+）：
  商单报价 300-800/条
  + 开通收纳师/整理服务接单（本地 300-800 元/单）
  + 可选：广莞探店副线（厨具店/家居店探店与主赛道人设无缝衔接）
```
