# 07 · 个人定制方案（最终定稿 v3）：广莞租房攻略 × 租房好物

> 本文档是**最终执行方案，优先级最高**，覆盖 01/02/06 的通用结论。
> 画像：程序员、会用 AI、无货源、不出镜、东莞/广州、家有可拍空间+厨房。
> 决策演化：AI 干货赛道（兴趣不足）→ 家居收纳（拍摄强度大，"拍起来很累"）→ **租房攻略 + 租房好物（v3 定稿）**。
> 拍摄底线：可以微实拍，但拒绝高强度拍摄 → 本方案实拍量 ≈ 每周 30 分钟以内。

## 一、赛道决策（定稿 v3）

**内容结构 = 70% 攻略型纯图文（零拍摄）+ 30% 好物清单型（最低实拍）**

| 维度 | 判断 |
|---|---|
| 拍摄量 | 攻略类靠查资料+截图+AI配图，零拍摄；好物类只拍产品本体 2-3 张（每件 10 分钟）✅ |
| 不出镜 | 攻略本就不需要人，好物只拍物 ✅ |
| 无货源 | 攻略无成本；好物挂车不囤货（自购样品 19.9-49.9 元决策品即可）✅ |
| 流量逻辑 | "广州租房/东莞租房/租房避坑"搜索量巨大且常年稳定；攻略=收藏型内容，正中 CES 收藏权重 ✅ |
| 转化闭环 | 搜攻略的人=刚租房要买好物的人：攻略建立信任 → 好物笔记接住消费 ✅ |
| 个人优势 | 程序员整理信息出攻略 = 降维打击；AI 承担图表/封面/文案初稿 ✅ |

**为什么不是纯收纳**：收纳改造是拍摄强度最大的赛道（改房间、拍步骤、摆场景），与"拍起来很累"冲突。本方案保留收纳好物作为变现品类，但砍掉"改造过程"内容形态。
**为什么不是纯 AI 生成**：AI 视频假房间挂车 = 虚假种草高危 + 信任崩塌；AIGC 内容须标注。攻略类反而是 AI 原生可行的形态（AI 配图+图表不涉及虚假体验）。

## 二、内容模型（两种笔记形态）

### 形态 A · 攻略干货（70%，零拍摄）

- **来源**：知乎/贝壳/自如/链家公开数据、政府租赁政策、自己经历
- **形态**：图文卡片（信息图 + 大字封面），AI 配图 + 图表生成
- **选题**：见第五节
- **红线**：数据要标注来源和时效（"2026.11 整理"），错误信息会毁掉攻略号信任

### 形态 B · 打工人好物（30%，最低实拍）—— 全场景，不限于收纳

- **形态**：单品实测（产品本体 2-3 张照 + 使用场景 1 张）或清单合集（每件 1 张）
- **垂直度策略**：**人群垂直 > 品类垂直**——账号标签锚定"广莞租房打工人"，好物覆盖这个人群的全部消费场景（桌搭/通勤/睡眠/口粮/清洁），算法照样给你精准人群，还能避免同品类选题枯竭
- **选品四原则**（每件选品前过一遍）：
  1. **决策快**：19.9-99 元，看两眼就能下单
  2. **拍得简单**：产品本体 2-3 张照能讲清楚，不需要过程演示
  3. **佣金合理**：挂车佣金 10-30%，避开"后台收益高、实际到手极低"的高返点坑
  4. **人群重合**：租房打工人会买的东西（详见下方品类池）
- **挂车**：第 10 篇起每篇挂车
- **素人感**：每篇写一个真实缺点，不说"闭眼入"

**打工人好物品类池**（与租房攻略人群全部重合）：

| 品类 | 代表选题方向 | 为什么适合 |
|---|---|---|
| 桌搭/数码外设 | 键鼠、显示器支架、拓展坞、升降桌垫 | 程序员审美是选品雷达，参数你看得懂；客单价高佣金可观 |
| 工位办公 | 人体工学低配、护腰垫、显示器灯、桌面绿植 | 攻略粉=久坐打工人，精准 |
| 通勤路上 | 耳机、充电宝、通勤包、地铁降噪好物 | 广莞通勤是攻略内容自然延伸 |
| 睡眠/氛围 | 遮光帘、香薰、小夜灯、褪色贴 | 租房痛点直接相关，收藏率高 |
| 口粮零食 | 办公室零食、冲饮咖啡、低卡速食 | 复购型品类，决策最快 |
| 清洁神器 | 一次性清洁、除螨、冰箱除味 | 租房退租场景强关联 |
| 平价替代 | 大牌平替类日百 | "平替"是小红书搜索超级词 |

**红线**：食品/母婴/美妆等类目涉及资质与安全声明，起号期不碰（无货源无法保证品质背书）；数码类商单后期最值钱，前期靠好物攒信任。

## 三、AI 生产工作流

```
选题：搜索热词监控（贝壳/链家成交热度、"广州租房"下拉词）
      + scripts/xhs_collector.py 采竞品 Top 笔记
攻略：AI 整理资料 → 手动核实关键数据（房租区间/通勤时间）→ 出图文卡片
好物：AI 写初稿 → 手加 1 个真实缺点
封面：AI 排版（大字对比图："城中村 800 vs 小区 1500"）
复盘：每周日 CSV → 算收藏率 → 调整 A/B 形态配比
```

⚠️ AIGC 图片用于信息图/配图 OK（与虚假体验无关），人物/商品假图禁止。

## 四、变现路径（三段式）

```
第 1-3 个月（0→千粉）：
  攻略图文起号 + 第 10 篇起好物挂车
  + 素人通告（家居/日百类，30-200 稿费+产品）

第 4-6 个月（千粉后）：
  蒲公英商单：家居/日百/家电类（租房人群画像精准，家居 500 粉有机会人工审核开通）
  + 挂车双线并行

第 7 个月以后（5000 粉+）：
  商单报价 300-800/条
  + 本地线索变现：搬家/保洁/长租公寓合作（私信接单，主页简介合规引流）
  + 可选：收纳好物场景微实拍（信任建立后再逐步加）
```
