## 二、为什么是家电选购

四条理由，缺一条这个结论就不成立。

### 1. 纯图文可行，且不需要买样品

家电攻略的素材是：官方参数页、能效标识、电商价格页、用户评价、国标条款、搜索下拉词。全部是**截图和表格**，没有一张需要实拍。

这是 3C 测评做不到的——3C 要跑分、要测续航、要拍产品细节，必须有实物。家电的「决策信息」是公开的，壁垒不在样品，在整理方式。

### 2. 商业需求全平台第一

千瓜数据（2026.4.21-5.21）商单笔记投放热度：

| 排名 | 类目 | 商单笔记数 | 占比 |
|---|---|---|---|
| 1 | **家居家装** | 13.34 万 | 12.75% |
| 2 | 母婴育儿 | 12.24 万 | 11.7% |
| 3 | 美食饮品 | 12.23 万 | 11.69% |

品牌预算最厚的类目，才轮得到小账号接单。美妆、穿搭的商单早就被 MCN 和头部锁死了。

### 3. 搜索意图最明确

「洗烘一体还是洗烘套装」这种问题，用户是带着钱来的，不是来消遣的。这类内容有三个特征：

- 决策周期长 → 一条笔记能吃 30-90 天的搜索长尾
- 收藏率高 → 正中 CES 收藏权重（18%）
- 转化路径短 → 看完就知道买哪台，直接点商品卡

### 4. 能力匹配是稀缺的

家电区会念参数的人一大把，会做**差评聚类、价格分位、按户型决策表**的人极少。这正是程序员能做、纯内容博主做不了的东西。

### 第一个切口为什么是洗烘

- **增速最猛**：2026 上半年洗烘笔记增长 **120%**（空调 133%、冰箱 104%、家具 57%、智能家居 49%）
- **季节对**：11 月定稿，南方进入湿冷季，烘干是当下真实痛点
- **有本地体感**：广莞回南天 + 冬季湿冷，这是能写出细节的场景，不是隔空分析
- **天然有争议**：「洗烘一体是不是智商税」「冷凝 vs 热泵」这类对立话题自带评论区

## 三、和旧方案的关系

决策演化过四轮，每一轮被否掉都有明确原因：

| 版本 | 方向 | 被否原因 |
|---|---|---|
| v1 | AI 干货 | 兴趣不足，写不下去 |
| v2 | 家居收纳 / 租房改造 | 要实拍、要真房、要施工，拍摄成本高 |
| v3 | 广莞租房攻略 × 租房好物 | 起号容易，但粉丝消费力弱、生命周期 1-2 个月，商单单价低**（最容易起号 ≠ 最容易赚钱）** |
| v4 | 3C 数码测评 | 单价最高，但要样品、要设备、要测试，与「图文 + 不拍摄」冲突 |
| **v5（本文）** | **家电选购** | 家电 = 家居的广告需求 + 3C 的参数逻辑，但**不需要样品** |

关键判断：**v3 的问题不是方向错，是目标错。**它优化的是「起号速度」，而这个项目真正需要的是「单位时间的变现效率」。

## 四、账号设定

### 名字

原则：带品类词（可被搜索）+ 有人格感（不像营销号）+ 不锁死单一品类（后面要扩冰箱空调）。

| 候选 | 说明 |
|---|---|
| **阿选的家电笔记** | 推荐。「选」直接指向决策，可扩品类 |
| 参数翻译官 | 差异化强，但略像工具号，人格感弱 |
| 老周选家电 | 有人格、易记，但锁死「家电」，扩 3C 时略尴尬 |

### 简介模板

```
帮普通人选家电，不念参数表
洗烘 / 冰箱 / 空调｜参数对比 + 差评聚类
每周 2 篇，评论区问型号，我拆给你看
```

### 主页三件套

- **头像**：不用真人脸。用「对比表格截图」或纯色底 + 文字，保持工具感
- **置顶 3 篇**：① 我怎么选家电（方法论）② 洗烘全系对比（干货合集）③ 高频问题答疑
- **领域标签**：只发家电/家居，前 20 篇不要发任何生活日常，否则标签会糊

### 明确不做

- 不出镜、不口播、不直播
- 不拍 vlog、不拍开箱视频
- 不买 3000 元以上的大件样品
- 不做本地服务线索（搬家/保洁/装修）
- 不写「全网最低」「闭眼入」这类极限词

## 五、内容四大类型

这四类循环发，比例建议 **3:3:2:2**。

### 类型 1：对比型（占 30%）

回答「A 和 B 该买哪个」。

- **结构**：结论先行 → 6 项参数逐条对比表 → 三种人群分别选谁 → 一句话总结
- **素材**：官方参数页截图 + 自制对比表
- **指标**：收藏率最高的一类，目标 ≥5%

### 类型 2：差评聚类型（占 30%）★ 账号差异化核心

回答「这机器有什么真问题」。

- **结构**：采样说明（样本量 + 时间）→ 差评归类图 → 被骂最多的 4 个问题 → 哪些是真缺陷、哪些是误用
- **素材**：平台评价页手工抽样（每型号 ≥100 条）+ 自制占比图
- **指标**：评论区最活跃的一类，目标评论 ≥20 条

### 类型 3：价格分档型（占 20%）

回答「我这个预算该买什么」。

- **结构**：三档预算 → 每档的「必须有的功能 / 可以砍的功能」→ 各档代表机型 → 加钱能买到什么
- **素材**：电商价格页 + 参数表
- **指标**：转化最好的一类，挂车主要放这里

### 类型 4：场景算账型（占 20%）

回答「到底值不值」。

- **结构**：一个具体场景（回南天/三口之家/租房）→ 算一笔账（购机 + 电费 + 时间）→ 值/不值的临界点
- **素材**：电价、能效标识、使用频次假设
- **指标**：转发最高的一类，适合做「地域 + 季节」选题

## 六、前 5 篇执行卡

> 第 2 篇是**差异化样板**。做完这一篇，就知道这条路走不走得通。

### 第 1 篇｜洗烘一体和洗烘套装，差的不只是钱

- **封面**：上「别买错」／下「6 项参数逐条对比」
- **正文骨架**：
  1. 一句话结论（什么人买一体、什么人买套装）
  2. 6 项参数对比表：容量、烘干方式（冷凝/热泵）、烘干时长、绒毛处理、安装条件、故障率
  3. 三类人群选择建议：租房 / 小三房 / 有阳台
  4. 结尾互动：「你家阳台多大？评论区说下我帮你判断」
- **数据来源**：官方参数页、能效标识、GB/T 家用电器相关标准
- **风险**：不点名贬低具体品牌，用「A 类/B 类」或「某型号」表述

### 第 2 篇｜我扒了 3000 条差评，烘干机被骂最多的是这 4 点 ★

- **封面**：上「3000 条差评」／下「只有 4 个真问题」
- **正文骨架**：
  1. 采样说明：3 个主流型号、各 1000 条、时间范围、如何归类（**必须写，这是可信度来源**）
  2. 差评归类占比图（自制柱状图或饼图）
  3. 4 个真问题：绒毛堆积 / 烘不干厚件 / 噪音 / 售后响应——每条给「发生率 + 怎么规避」
  4. 哪些是误用（把「烘不干」拆成「装太满 / 没选对程序」）
  5. 结尾互动：「你踩过哪个？」
- **数据来源**：平台评价页手工抽样，标注样本量与采样日期
- **风险**：引用差评必须打码用户名与头像；不写「某某品牌质量差」，只写「某型号该类问题占比 X%」

### 第 3 篇｜3000 / 6000 / 10000 三档洗烘，各买哪台

- **封面**：上「三档价位」／下「各买哪台，一句话结论」
- **正文骨架**：三档 → 每档「必须有 / 可以砍」→ 代表机型 2-3 个 → 加钱能买到什么
- **数据来源**：电商实时价格页（**必须标价格日期**，家电价格波动大）
- **风险**：价格会变，标题里不要写死具体金额以外的承诺；注明「价格为 X 月 X 日」

### 第 4 篇｜南方回南天，烘干机值不值这 5000 块

- **封面**：上「算一笔账」／下「一年用电 + 省下的时间」
- **正文骨架**：
  1. 场景描述（广莞回南天：墙面出水、衣服三天不干）
  2. 算账：购机 5000 ÷ 8 年 + 年电费（按能效和频次）+ 对比晾晒的隐性成本
  3. 临界点：一年用多少次才划算
  4. 不适合买的人（有朝南大阳台 / 一年用不到 30 次）
- **数据来源**：居民电价、能效标识、气象数据
- **风险**：电价按档位写区间，不要给单一数字

### 第 5 篇｜销售不会主动说的 5 个洗烘参数

- **封面**：上「这 5 个词」／下「多花 2000 也买不到体验」
- **正文骨架**：5 个参数逐个「听起来很厉害 → 实际影响是什么 → 要不要为它加钱」
- **数据来源**：国标定义 + 参数页 + 用户反馈
- **风险**：不要写「销售骗你」，改成「这 5 个词容易被误解」，避免对立表述

## 七、变现节奏

| 阶段 | 时间 | 动作 | 收入预期 |
|---|---|---|---|
| 起号期 | 第 1-3 月 | 只写攻略，**不挂车**（账号未满 180 天无法开通） | 0 |
| 验证期 | 第 4-6 月 | 攻略 + 百元小件（清洁、收纳、除湿）挂车 | 几百 - 2000/月 |
| 成长期 | 千粉后 | 蒲公英图文商单 + **笔记授权分成** | 2000 - 5000/月 |
| 放大期 | 5000 粉后 | 虚拟商品（参数对比表、按户型决策表，9.9-29.9） | 5000+/月 |

**三条必须知道的规则**：

1. **0 粉挂车有前提**：账号注册满 180 天 + 实名认证。新号前半年挂不了车，这段只能靠置换和零星商单。
2. **笔记授权分成被严重低估**：1000-10000 粉可报名，过去 180 天的优质非商业笔记可授权品牌投流，拿授权费 + 广告消耗 ≥3% 分成，单次上限 5000。攻略篇最可能被选中。
3. **佣金率差异极大**：家居日用 8%-40%，3C 通常个位数。所以小件挂车、大件做商单，两条腿分开走。

## 十、红线

1. 参数与价格必须标来源和日期；家电价格波动大，一条过期价格会毁掉信任
2. 差评引用必须打码，不点名贬低具体品牌
3. 不写极限词：「最」「第一」「100%」「闭眼入」「绝对不会坏」
4. 商业笔记必须走蒲公英报备，占比不超过总笔记 30%
5. 不导流微信、不私域成交，虚拟商品在站内闭环
6. 不上架无资质商品，不做医疗/保健类功效表述
7. AI 生成的图必须标注，封面主图优先用真实截图（参数页、能效标识、评价页）
8. 不刷量、不买粉。数据造假一旦被识别，账号直接废
