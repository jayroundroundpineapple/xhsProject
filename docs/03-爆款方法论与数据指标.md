# 03 · 爆款方法论与数据指标（2026 算法版）

## 一、CES 算法权重（核心中的核心）

2026 年小红书 CES（Community Engagement Score）权重分布：

```
评论互动 35%  ← 权重第一，首次超过完读率
完读率   28%
收藏转发 18%
点赞关注 12%
点击率    7%
```

- **评论和转发的权重是点赞的 4 倍**。只追求点赞很难突破流量瓶颈。
- CES 参考公式：`点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8`
- 深度长评论、截屏等高质量互动权重更高；"评论区扣1"式互夸反而稀释信号。
- **运营动作**：每篇笔记文末抛开放式问题（如"你家桌面最头疼的是什么？"），主动引导主题讨论。

## 二、数据达标线（每周复盘对照）

| 指标 | 达标线 | 意义 |
|---|---|---|
| 初始曝光 | 200-500（新旧号一样） | 低于此=没跑出初始池 |
| 点击率 | ≥8% 健康线；<2.5% 必须改封面标题 | 流量第一道门槛 |
| 完读率 | >40% | 前几行留不住人会降权 40% |
| 收藏率 | ≥3% 进中级池；≥8% 有 90% 概率进 10 万+曝光池 | 收藏=长期实用价值信号 |
| 转粉率 | 持续监控 | 账号资产增速 |

**流量晋级逻辑**：新笔记 → 200-500 初始曝光测试 → 收藏率>8% 且点赞率>12% → 二级池 3000-8000 追加曝光 → CES 达标 → 中级池 5000-2 万曝光。
**限流红线**：连续 3 篇收藏率 <5% → 限流到基础池以下。

## 三、双轨分发：搜索流量是护城河

- 搜索占全站流量 **63%**；标题含具体问题的笔记点击率高 2.3 倍。
- 搜索流量笔记平均收藏率 6.8%，纯推荐流量只有 1.9%。
- **运营动作**：每篇笔记锁定一个搜索词（如"小户型收纳""桌面整理"），标题前置关键词，正文自然复现 2-3 次；持续占位关键词 = 不发新笔记也有稳定曝光。

## 四、图文爆款结构模板

- **封面**：竖屏 9:16（点击率高 3.8 倍）；前后对比图/清单图天然高互动；含实拍图、过程记录的互动率高 47%。
- **标题公式**：数字 + 痛点 + 悬念/反差。例："花 200 块改造工位，同事以为花了 2000"。
- **正文**：核心结论前置，每段 ≤4 行，总字数 ≤300；末尾抛互动问题 + 3-5 个精准话题标签。
- **发布**：素人感优先（过度滤镜降信任分）；广告内容必须报备，未报备广告第 5 天起数据断崖下滑。

## 五、爆文判断基准（按粉丝量级）

| 账号 | 小爆文 | 中爆文 | 大爆文 |
|---|---|---|---|
| 新号/小号 | 赞 500+ 藏 300+ | 赞 1000+ | 赞 5000+ |
| 1万-10万粉 | 赞 3000-1万 | 赞 1万+ | 赞 10万+ |
