# 05 · 竞品笔记拆解：《好物分享真的还能做吗？》

> 来源：https://xhslink.cn/o/Ar5me2fS9iJ （2026-11 抓取，含评论区）
> 这篇笔记的评论区是宝贵的一手情报：提问者是"想做的好物博主"，回答者是"正在做的人"。

## 一、笔记概况

- **主题**：新博主求证好物分享赛道现状，带话题 #好物种草 #自媒体人 #新人博主 #如何做博主。
- **笔记类型**：求助/经验贴——这类内容评论区极易引爆（评论权重 35%），适合用作我们自己"互动引流"的内容形态参考。

## 二、评论区提炼出的真实数据（情报价值最高）

| 角色 | 关键信息 | 对我们的启示 |
|---|---|---|
| 全职大号博主 | 两个大号月入 5 位数，都是今年做起来的；"没啥事是轻松月入过万的" | 收入天花板存在，但"轻松赚钱"是幻觉 |
| 兼职新人（7月起步） | 8 月涨到千粉开蒲公英 → 图文一个月没做起来 → 9 月转视频 → 10 月接 11 条商单 × 300 元/条 | **图文不行就转视频**；千粉=商单起点；300/条是新人合理报价 |
| 转型博主 | 原大字报手持博主转型好物；自费买产品实测，主打真实分享，不花钱堆布景 | 素人感+自费实测=信任路径；道具成本控制住 |
| 实操新人 | 本月后台收益 2000 但实际到手远低于此，返点太高 | **选品要看实际到手佣金，后台数据打 5 折评估** |
| bot 起号派 | bot 号 2 万粉后再实拍；先拍收纳盒/厨房好物/家居收纳，流量起来再拍 muji/韩系彩妆 | 内容进阶路线：刚需品 → 流量品（但 bot 阶段慎用，见 02 文档） |
| 起号正确派 | "保证粉丝画像、活跃度符合好物博主要求；坚持在牌桌上，半年后才能拿大结果" | 画像 > 粉丝数量；战线预期 ≥6 个月 |

## 三、评论区识别的风险信号

1. **卖课收割**：有评论直接提醒"很容易被卖课的收割"。
2. **灰产兜售**：评论区出现卖真人赞、真人粉丝、资源群的人——全部远离，买量=封号风险+画像污染。
3. **收益幻觉**：平台后台收益 ≠ 实际到手，返点和税率会吃掉大半。

## 四、可复用的内容机会（从评论区挖选题）

- 求助型爆文空间大：大量"怎么起号/怎么涨粉"的追问 → 这类笔记 ourselves 可以写（见选题库 #26-28）。
- "后台收益 vs 实际到手"避坑贴是差异化选题。
- "兼职 4 个月从 0 到 11 条商单"这类过程记录贴互动极高 → 我们发"起号日记"系列。

## 五、补充评论区情报（二轮抓取）

| 角色 | 关键信息 | 对我们的启示 |
|---|---|---|
| bot起号派（完整原文） | "先发 bot 把粉涨起来，bot 小号 2w 粉；不建议 0 粉就开始拍，会很痛苦。转型后先拍梳妆台收纳盒/厨房好物/家居收纳等实用日常品，流量起来再拍 muji 和韩系彩妆等流量品；出了爆款就开始有单，现在两个号接单都破 W" | 完整进阶路线图：**刚需品起号 → 流量品放量 → 爆款 → 接单**。但 bot 段落仅适用于"纯涨粉"目标，画像问题见 02 文档分析 |
| **两年老玩家（反面样本）** | "做了两年多了还没过 W，拖后腿了。**维护数据、返点都是支出**" | 极重要的反面情报：① 收入分布是长尾的，中位数远低于"月入过万"的宣传；② **"维护数据"（买互动）是纯支出且违规**——不买数据才是成本最优解；③ 返点持续侵蚀利润，选品必须算"实际到手"而非"后台显示" |

**综合结论修正**：评论区呈现的是幸存者偏差 + 现实底色的混合。合理预期应为——兼职做：月几百到两三千（4-6 个月内）；全职+坚持 1 年以上：有机会过万但不保证。**所有"轻松月入过万"的叙事都要打折听**，且永不买数据。

## 六、结论

好物分享赛道：**能做，难度上升，半年起就有回报**。路径 = 兼职起步 → 千粉开蒲公英 → 图文/视频双轨 → 300 元商单起步 → 半年看结果。
