## 2. 三个核心模块

### A · 题材雷达 Topic Radar
**输入**：切口（洗烘 / 冰箱 / 空调）、目标人群、季节、已发笔记、`notes_log.csv`
**输出**：候选题材列表 + 四维评分 + 象限图

| 评分维度 | 依据 |
|---|---|
| 搜索意图 | 是否带明确决策词（"还是""怎么选""值不值"） |
| 变现距离 | 离挂车/商单/虚拟商品哪条路最近 |
| 素材可得 | 官方参数页、电商页、评价页是否拿得到 |
| 竞争度 | 同题材已发密度；避开重复 |

**内置规则**：
- 四类内容比例 3:3:2:2（对比 / 差评 / 价格 / 场景）
- 10 篇止损线提醒：收藏率 <3% 且曝光 <5000 → 换切口
- 已发过的题目标记，防止重复

**可视化**：散点象限图（横轴竞争度、纵轴搜索意图）+ 右侧候选列表；点选题进入 B。

---

### B · 文案工坊 Copy Studio
**输入**：选题 + 内容类型（对比 / 差评聚类 / 价格分档 / 场景算账）
**输出**：

| 产物 | 规则 |
|---|---|
| 标题 A/B/C | A 搜索友好、B 反差钩子、C 检索型；两个搜索词进前 15 字 |
| 正文骨架 | 500-800 字；前 100 字给结论；中段表格化 |
| 标签 | 5 个；前两个搜索词，第三个长尾，后两个人群池 |
| 红线自检 | 极限词 / 来源日期 / AI 标注 / 导流 / 差评打码 / 商业报备 / 用户新增"图上不显示来源时间" |

**可视化**：左侧正文结构树（结论 → 对比 → 人群 → 互动），右侧实时预览，底部红线清单绿/红状态。
**导出**：复制 Markdown，或写到 `content/` 下新笔记草稿。

---

### C · 图片编排 Storyboard
**输入**：选题 + 文案 + 真实素材库（`product.png`、`price.png`、`content/reference/`）
**输出**：6 图任务单，每页含「目标 / 主视觉 / 页面文案 / 数据来源 / 是否 AI / 红线状态」

**内置规则**：
- 主推 1242×1660；封面钩子 + 5 张内页
- 内页必须保留真实商品图与当天实采价格
- **配图内不显示"截自哪里 / 什么时间"**（用户 2026-11-21 明确要求）
- AI 场景图必须标注"场景示意 · 非实拍"
- 相邻两张换构图（大字 / 清单 / 数字 / 对比轮着来）

**可视化**：横向 6 卡片时间轴，可拖拽排序；点卡片展开字段。
**导出**：生成 huashu-design HTML 骨架 → 调用 `xhs_render.py` 出图（P2 实现）。


## 4. 数据与接口边界

| 项 | 方案 |
|---|---|
| 形态 | 纯前端单页 HTML，离线可用，无需后端 |
| 规则数据 | 内置 JSON：四类模板、前 5 篇卡、止损线、红线清单 |
| 用户草稿 | `localStorage` 本地保存，不上传 |
| 读取 CSV | 用户手动选择 `data/notes_log.csv`（File API），不自动扫描磁盘 |
| AI 生成 | **v1 不接 LLM**，用模板 + 规则生成；v2 可选接入，需用户决定 key/方式 |
| 图片生成 | v1 只出任务单 + HTML 骨架；不直接调图像模型 |

> 如果要做成在线链接或需要账号/云存储，另走 `cloud-service` + 发布流程；本方案默认本地文件。

## 5. 合规边界（写死在工具里）

1. 不自动发布、不自动回评、不刷量
2. 价格/参数的来源与日期留在文档和核对表；**配图内不显示来源/日期行**
3. 差评引用打码，不点名贬低品牌
4. 无极限词（最 / 第一 / 100% / 闭眼入 / 绝对不会坏）
5. AI 图标注；商业笔记报备且 ≤30%
6. 不导流微信、不私域成交
7. 不伪造截图、不编造数字
