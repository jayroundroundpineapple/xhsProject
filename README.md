## 快速结论（先看这个）

> 2026-11-10 定稿：作者画像 = 程序员 / 会 AI（仅作生产工具）/ 无货源 / 不出镜 / 广莞 / 家有可拍空间+厨房。曾考虑 AI 干货赛道，因兴趣不足+变现周期偏慢放弃。**最终赛道见 `docs/07-个人定制方案-家居收纳.md`（优先级最高）**：

1. **主赛道**：「家居收纳 / 租房改造」——环境空镜+手部操作拍摄，不露脸、无货源，收藏率全品类最高（↑65%），挂车 0 粉可做。
2. **内容延展**：厨房收纳/厨具（家里有厨房场景）。
3. **AI 用法**：AI 是生产力不是内容——文案初稿、封面排版、TTS 配音、数据复盘，正文必须手改 20-30% 防 AI 味。
4. **变现路径**：0 粉挂车（收纳盒/免打孔架，佣金 10-25%）+ 素人通告 → 千粉开蒲公英接家居商单（500 粉有机会人工审核开通）→ 5000 粉报价 300-800/条 + 收纳师服务接单。
5. **关键数据线**：收藏率 ≥3% 进中级流量池、≥8% 有 90% 概率进 10 万曝光池；评论互动权重 > 点赞 4 倍。
6. **节奏**：每周 4-5 篇图文，前 20 篇只拍一个细分（桌面或厨房抽屉二选一）。

# 输出 → data/xhs_notes_平价收纳.csv
