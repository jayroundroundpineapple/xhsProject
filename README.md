## 快速结论（先看这个）

> 2026-11-10 定稿：作者画像 = 程序员 / 会 AI / 无货源 / 不出镜 / 广莞。**最终赛道见 `docs/07-个人定制方案-AI程序员.md`（优先级最高）**：

1. **主赛道**：「AI 工具 & 程序员效率干货」——纯图文+录屏，不出镜、无货源，虚拟商品净利率 80%+。前 10 篇聚焦「打工人 AI 效率工具」细分。
2. **副赛道**（第 2-3 个月）：广莞本地探店（不露脸）+ 帮商家做小程序的私域接单。
3. **变现路径**：0 粉挂 9.9 元提示词包/付费笔记 → 千粉开蒲公英接 AI/数码商单 → 万粉做知识付费/AI 咨询/代运营（三段式组合）。
4. **关键数据线**：收藏率 ≥3% 进中级流量池、≥8% 有 90% 概率进 10 万曝光池；评论互动权重 > 点赞 4 倍；AI 数字人内容必须标注 AIGC。
5. **节奏**：每周 4-5 篇图文，前 90 天死磕收藏率和搜索关键词占位。

## 数据采集快速上手

```bash
pip install requests pandas
python scripts/xhs_collector.py --keyword "平价收纳" --pages 3
# 输出 → data/xhs_notes_平价收纳.csv
```
