## 快速结论（先看这个）

> **2026-11-14 定稿 v5**：赛道 = 家居大类 → **家电选购**，形态 = **纯图文（零实拍 / 不出镜 / 不直播 / 不买大件样品）**，第一个切口 = **洗烘**。完整执行版见 `docs/09-执行定稿-家电选购.md`。

1. **主赛道**：家电选购（洗烘 → 冰箱 → 空调）。定位句：**用数据和差评帮你选家电，不念参数表**。
2. **为什么是它**：家居家装是平台商单量第一的类目（13.34 万篇，占 12.75%）；洗烘笔记 2026 上半年增长 120%；家电参数与评价全部公开，素材就是参数页与评价页截图，**不需要买样品**。
3. **内容四类**：对比型 30% / 差评聚类 30% / 价格分档 20% / 场景算账 20%。每周 2 篇，约 5 小时，全部零实拍。
4. **变现节奏**：前 3 个月零收入（账号未满 180 天无法挂车）→ 第 4-6 月小件挂车 → 千粉后蒲公英图文商单 + 笔记授权分成 → 5000 粉后虚拟商品（9.9-29.9 一份）。
5. **止损线**：10 篇后若无一篇收藏率 ≥3% 且曝光 ≥5000，**换切口不换赛道**；20 篇后仍不行才换赛道；连续 8 周写不出来就停。
6. **历史方案**：`01`/`02`/`07` 的「租房攻略」主线结论已废弃——起号快，但粉丝消费力弱、生命周期 1-2 个月、商单单价低。

> **废弃原因**：这个方案优化的是「起号速度」，不是「单位时间变现效率」。租房人群是任务型用户，消费生命周期只有 1-2 个月，粉丝单价低。同等工作量做家电，商单报价和佣金率都更高。

## 数据采集快速上手

# 输出 → data/xhs_notes_平价收纳.csv
