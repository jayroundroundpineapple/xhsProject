## 快速结论（先看这个）

1. **赛道推荐**：首选「家居收纳 / 平价好物」细分赛道切入好物分享（竞争低于美妆、收藏率高、拍摄成本低），详见 `docs/01`。
2. **变现路径**：1000 粉开通蒲公英接商单 → 5000 粉后报价提升，同时挂买手链接吃佣金（双线变现）。
3. **关键数据线**：收藏率 ≥3% 进中级流量池、≥8% 有 90% 概率进 10 万曝光池；评论互动权重 > 点赞 4 倍。
4. **节奏**：每周 4-5 篇图文 + 1-2 条视频，前 90 天不看短期收益、死磕收藏率和搜索关键词占位。

## 数据采集快速上手

```bash
pip install requests pandas
python scripts/xhs_collector.py --keyword "平价收纳" --pages 3
# 输出 → data/xhs_notes_平价收纳.csv
```

采集方案详解（含登录态配置、评论抓取、第三方数据平台替代方案、合规边界）见 `docs/04-数据采集方案.md`。
