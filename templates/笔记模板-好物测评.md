# 笔记模板：好物测评（图文）

> 使用方法：替换【】内容即可发。封面 = 第 1 图（前后对比或清单图，9:16 竖屏）。

## 标题（选一个公式）

1. 花【金额】块搞定【场景】，别人以为我花了【金额×10】
2. 【场景】救星｜这【N】样东西我回购了【N】次
3. 后悔没早买！【痛点人群】必收的【N】件平价好物
4. 【场景】实测【N】天｜这【N】样是智商税，这【N】样真香

## 正文结构（≤300 字）

```
【开头钩子·1行】
说真的，【痛点场景】困扰了我好久，直到我……

【核心结论前置·1-2行】
直接说结论：这 N 样最值得买，第 X 样闭眼入。

【逐个好物·每样 2-3 行】
1️⃣ 【品名】【价格】
✔️ 解决什么问题（具体场景，不吹参数）
❌ 小缺点也要写（真实感=信任）
👉 适合谁买

（重复 3-5 样）

【结尾互动提问·1行】
你家【场景】最头疼的是什么？评论区聊聊👇
```

## 话题标签（3-5 个）

#好物种草 #桌面收纳 / #租房好物 / #平价好物分享 #好物测评 【品类垂直标签】

## 发布检查清单

- [ ] 封面 9:16 竖屏、有前后对比或大字清单
- [ ] 标题含目标搜索词（关键词前置）
- [ ] 正文每段 ≤4 行，有真实缺点描述（素人感）
- [ ] 文末有互动问题
- [ ] 图片 ≥4 张，含一张"清单汇总图"（收藏利器）
- [ ] 带商品链接（开车后）/ 或标好"评论区蹲链接"
